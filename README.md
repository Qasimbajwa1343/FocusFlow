# FocusFlow

FocusFlow is an Android productivity application designed to help students reduce doom scrolling and improve study habits.

## Features

* Screen time tracking
* Focus timer
* Study reminders
* Productivity analytics
* App usage monitoring
* Focus streak tracking

## Technologies Used

* Java
* XML
* Android Studio
* SharedPreferences
* AlarmManager
* BroadcastReceiver
* UsageStatsManager

## Purpose

The application helps users understand their app usage behavior and encourages productive study sessions through reminders and analytics.

## Future Improvements

* Cloud synchronization
* User accounts
* AI-based productivity recommendations
* Weekly productivity reports
